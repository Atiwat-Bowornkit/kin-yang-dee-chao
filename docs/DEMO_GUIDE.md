# Demo Guide — สาธิตแอปใน ~5 นาที

## เตรียมก่อนเดโม

1. ติดตั้ง `build/app/outputs/flutter-apk/app-release.apk` (v1.2.0) บนเครื่องที่จะใช้
2. ตั้งค่า › การเชื่อมต่อ AI → ใส่ API key → **ทดสอบการเชื่อมต่อ** ให้ขึ้น "ทดสอบล่าสุด: สำเร็จ"
3. ตั้งค่า › ความช่วยเหลือ → เปิด **โหมดสาธิต** (แสดงขั้นตอนและบันทึกการเรียก AI ที่ไม่มีข้อมูลลับ)
4. เตรียมวัตถุดิบจริง 3–4 อย่าง (เช่น ไข่ มะเขือเทศ หอมใหญ่) หรือรูปไว้ในแกลเลอรี
5. สำรอง: ถ้าเน็ตไม่ดี ใช้ "เลือกเอง" (ไม่ต้องใช้ AI) — สูตรในแอปทำงานออฟไลน์ได้ทั้งหมด

> อย่าเปิด "แสดง key" ระหว่างเดโม/อัดหน้าจอ

## ลำดับการเดโม

| # | ทำ | สิ่งที่ควรพูด |
|---|---|---|
| 1 | หน้าสแกน → ถ่ายภาพ/จากแกลเลอรี → วิเคราะห์ | รูปถูกส่งไปที่โมเดลของผู้ให้บริการผ่าน API — แอปไม่ได้ฝึกโมเดลเอง หน้าโหลดแสดงเวลาที่ผ่านไปจริง ไม่เดาเปอร์เซ็นต์ |
| 2 | หน้า **ตรวจวัตถุดิบ** | AI อาจผิด จึงไม่หาเมนูทันที — แต่ละรายการบอกว่า "AI ตรวจพบ" หรือ "เพิ่มเอง" |
| 3 | แก้ชื่อ 1 รายการ, ลบ 1 รายการ | แอปจำว่าแก้อะไร ("แก้จากผล AI: …") และเก็บผล AI เดิมไว้ดูเทียบ |
| 4 | เลือกของพื้นฐานในครัว | ของเหล่านี้ผู้ใช้เลือกเอง ไม่ได้มาจากรูป |
| 5 | **ยืนยันวัตถุดิบและหาเมนู** | ตอนนี้แอปใช้เฉพาะรายการที่ยืนยัน |
| 6 | แตะ **เงื่อนไขการทำอาหาร** → ไม่เกิน 15 นาที, ไม่เผ็ด | สูตรที่ไม่ผ่านไม่ได้หาย — ซ่อนไว้ใต้ "ดูอีก N เมนูที่ไม่ตรงเงื่อนไข" |
| 7 | เปิดสูตรอันดับแรก → "ทำไมแนะนำเมนูนี้" | "มี 2/2 อย่าง" คือความครบของวัตถุดิบ ไม่ใช่ความมั่นใจของ AI; บอกว่าขาดอะไร/ต้องเตรียมอะไร |
| 8 | กลับ → **ขอเมนูจาก AI ตามวัตถุดิบและเงื่อนไขนี้** | AI ถูกเรียกเมื่อกดเท่านั้น; แอปตรวจทุกสูตรที่ได้ — สูตรที่ไม่ครบถูกทิ้งและนับไว้ |
| 9 | เปิดสูตร AI | ป้าย "สูตรจาก AI", เวลา "≈", kcal "ไม่ทราบ" (ไม่ใช้ตัวเลขที่ AI เดา) |
| 10 | ปรับจำนวนที่ → เพิ่มของที่ขาดลงรายการซื้อ | ปริมาณคูณเฉพาะตัวเลข; รายการซื้อรวมหน่วยเดียวกัน แยกหน่วยต่างกัน |
| 11 | เริ่มโหมดทำอาหาร | หน้าจอไม่ดับระหว่างทำ ออกแล้วปล่อยการล็อกหน้าจอ |
| 12 | ไอคอน **สรุปการวิเคราะห์** (มุมขวาบนของหน้าผลลัพธ์) | ก่อน/หลังการตรวจ, ขั้นตอน AI/แอป/ผู้ใช้, บันทึกการเรียก AI (เวลา, สถานะ, ผลตรวจ) — ไม่มี key/header |
| 13 | แชร์สูตร → รูปการ์ด | การ์ดระบุแหล่งสูตร |

## คำถามที่อาจถูกถาม

- **AI แม่นแค่ไหน?** ขึ้นกับโมเดลของผู้ให้บริการและภาพ — จึงมีขั้นตรวจและยืนยันก่อนเสมอ
- **ไม่มีเน็ตใช้ได้ไหม?** เลือกวัตถุดิบเอง, สูตรในแอป 65 เมนู, ประวัติ, เมนูโปรด, ซื้อของ ใช้ได้; ผล AI ที่เคยขอไว้ดูซ้ำได้
- **key ปลอดภัยไหม?** เก็บแบบเข้ารหัสในเครื่อง ส่งผ่าน https เท่านั้น ไม่อยู่ใน log/trace/การแชร์
- **ทำไมเมนูนี้มาก่อน?** ดูกฎลำดับในหน้าสรุปการวิเคราะห์ (ผ่านเงื่อนไข → ครบกว่า → ขาดน้อยกว่า → ตรวจไม่ได้น้อยกว่า → เร็วกว่า)

## ถ้ามีปัญหาระหว่างเดโม

| อาการ | ทางแก้ |
|---|---|
| "ไม่สามารถเชื่อมต่อบริการ AI ได้" | เช็กเน็ต แล้วกดลองใหม่ หรือสลับไป "เลือกเอง" |
| "API key ไม่ถูกต้อง" | ตั้งค่า › การเชื่อมต่อ AI → ใส่ใหม่ → ทดสอบ |
| "บริการ AI มีผู้ใช้มาก" (rate limit) | รอสักครู่แล้วลองใหม่ สูตรในแอปยังใช้ได้ |
| AI ไม่พบวัตถุดิบ | ถ่ายใหม่ให้แสงพอ หรือกด "เลือกวัตถุดิบเอง" ในหน้าตรวจ |
